# Dipanshi ka Play Box — Picture Story Box

Animated picture stories for kids, plus a **make-your-own story from pictures** mode.

- 🎬 Curtain intro, tap or swipe to move through scenes
- 🗣️ Read aloud in English or हिंदी (browser speech)
- 👆 Tap-to-help scenes: drop pebbles for the Thirsty Crow, walk the Tortoise, make it rain for the Little Seed
- 📷 Make your own: add photos, write a line for each, preview and save (stored in this browser only)

## Run

Open `index.html` in any browser — no build or server needed.

To put it online: repo **Settings → Pages → Deploy from branch → `main` / root**.
